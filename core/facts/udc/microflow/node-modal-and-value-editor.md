# 节点弹窗 + 值编辑器 + 表达式编辑器（用户逐节点口述，权威契约）

> 用户明确"我们一个一个节点来，我给你讲清楚"。本文件记录每个节点弹窗的完整结构，
> 以及跨节点通用的「字段值编辑器」和「表达式编辑器」机制。生成器必须照此。

## 一、跨节点通用的三样东西

### 1. 字段值编辑器（所有「字段赋值/参数映射」行共用）
每个字段的取值是三态之一：
- **常量**（Simple）：直接填值（文本/整数/布尔下拉 是/否 等）
- **引用**（SelectParam）：选前序节点出参的字段（变量下拉是**树形**：根=入参DTO / 实体对象，子=字段）
- **高级模式 = 表达式**（Expression）：点「高级模式」进表达式编辑器

### 2. 赋值方式（三态，插入/修改/修改变量等实体类节点通用）
- **字段映射**（attrs）：逐字段「字段下拉 + 值」行，+ 添加字段 / 批量添加
- **对象引用**（value）：选一个「选择来源参数」（引用实体变量整体）
- **自动映射**（auto）：按同名字段自动匹配（选来源参数后自动填）

### 3. 表达式编辑器（点「高级模式」弹出）
- 提示：字段变量或者函数，且在**英文输入法**下编辑
- 三栏：左=变量/字段树，中=函数分类，右=函数说明+示例
- 函数分类：基础函数 / 日期函数 / 数学函数 / 文本函数 / 条件函数 / 聚合函数 / 变化函数 / 校验函数
- 运算符快捷标签：`= != > < >= <= and or not true false ( ) 为空 不为空 包含(全部) 属于`
- 按钮：全量复制 / 部分复制 / 粘贴 / 清空 / **验证**（验证=前端校验表达式合法性）

## 二、修改变量（CHANGE_VARIABLE）弹窗

```
变量       必填  树形下拉：
                根① 入参DTO   例如「方案id [1.10删除方案数据入参Ska]」→ 子：是否全部删除[布尔]、方案id[长整数]、vKey[文本]
                根② 实体对象  例如「小爪验收实体全量」→ 子：创建时间[日期时间]、更新时间[日期时间]、创建人[实体]、创建机构[实体]…
赋值方式   必填  字段映射 / 对象引用 / 自动映射
  - 字段映射 → 参数映射（字段行 + 添加字段 + 批量添加）
  - 对象引用 → 选择来源参数（下拉：入参DTO / 实体对象）
  - 自动映射 → 自动匹配
```

## 三、插入数据（CREATE_ENTITY）弹窗（含批量添加）

```
选择应用   必填  默认「数据迁移 (当前应用)」
选择实体   必填  选实体后回填字段（树形，含 md5）
赋值方式   必填  字段映射 / 对象引用
字段赋值         选实体后渲染：字段行 + 「添加字段」
  - 「添加字段」→ 下拉选单个字段
  - 「批量添加」→ 弹窗多选 checkbox（ID[长整数]、创建时间[日期时间]、更新时间[日期时间]、是否草稿[布尔]…）+ 确定
节点出参名称 必填
```

## 四、铁律（用户反复强调）

1. 每个节点弹窗的必填项不同，必须逐个拉出来；**写进 JSON ≠ 确认**，必填没填全照样错。
2. 字段引用只能是**前序已创建**的变量（顺序 G8），且字段来自该变量的真实结构（树形下拉里有的才算数）。
3. 实体字段值有三态：常量 / 引用 / 高级模式(表达式)；表达式必须在英文输入法下编，走表达式编辑器。
4. 批量添加（插入/修改等）给的是 checkbox 多选字段，确定后批量生成字段行。
5. 入参是「参数」页签定义的 CUSTOM 入参 DTO（如 方案id），不是实体 DTO——两者在变量树里是两个根。

## 批量插入/批量更新 的「列表」语义（用户口述）

- 批量操作吃的是**实体列表 / 多条数据**，不是单条。
- 列表来源三种：① 创建列表节点出参 ② 前序节点出参带列表 ③ 查询多条数据(RETRIEVE_ARRAY)出参。
- 所以生成批量节点前，必须先有「列表」类前序出参；引用的数据类型是 [多条数据]。

# ISO/IEC 25010:2023 与 CVSS 4.0 参考文档

## 第一部分：ISO/IEC 25010:2023 软件产品质量模型

> 来源：ISO/IEC 25010:2023（2023年11月发布），取代 2011 版

### 概述

ISO/IEC 25010:2023 定义了软件产品质量模型，由 **9 个质量特性**组成（2011 版为 8 个）。2023 版的主要变化：
- 新增 **Safety（防危性）** 作为顶级特性
- "易用性（Usability）" 更名为 **Interaction Capability（交互能力）**
- "可移植性（Portability）" 更名为 **Flexibility（灵活性）**，新增 Scalability 子特性
- Security 特性新增 **Resistance（抗性）** 子特性

### 九大质量特性与审计映射

| # | 特性 | 子特性 | 审计维度 |
|---|------|--------|----------|
| 1 | **功能适用性 (Functional Suitability)** | 完整性、正确性、适当性 | 功能审计 |
| 2 | **性能效率 (Performance Efficiency)** | 时间行为、资源利用率、容量 | 性能审计 |
| 3 | **兼容性 (Compatibility)** | 共存性、互操作性 | 功能审计 |
| 4 | **交互能力 (Interaction Capability)** | 可识别性、可学习性、可操作性、用户错误防护、用户参与度、包容性、用户辅助、自描述性 | 交互审计 |
| 5 | **可靠性 (Reliability)** | 无故障性、可用性、容错性、可恢复性 | 功能审计 |
| 6 | **安全性 (Security)** | 机密性、完整性、不可否认性、可问责性、真实性、**抗性 (Resistance)** | 安全审计 |
| 7 | **可维护性 (Maintainability)** | 模块化、可复用性、可分析性、可修改性、可测试性 | 代码质量 |
| 8 | **灵活性 (Flexibility)** | 可测试性、适应性、**可扩展性 (Scalability)**、可安装性、可替换性 | 性能审计 |
| 9 | **防危性 (Safety)** ⭐ 新增 | 运行约束、风险识别、故障安全、危险告警、安全集成 | 专项审计 |

### Security 子特性详解（2023 新增 Resistance）

- **机密性 (Confidentiality)**：信息仅授权方可访问
- **完整性 (Integrity)**：信息不被未授权修改
- **不可否认性 (Non-repudiation)**：行为不可否认
- **可问责性 (Accountability)**：行为可追溯到主体
- **真实性 (Authenticity)**：身份和数据的真实性可验证
- **抗性 (Resistance)** ⭐ 新增：系统抵抗攻击的能力，包括抵御暴力破解、DoS、自动化滥用等

### Safety 子特性详解（2023 全新）

- **运行约束 (Operational Constraints)**：在规定约束内运行以避免危害
- **风险识别 (Risk Identification)**：识别可能导致危害的风险
- **故障安全 (Fail Safe)**：故障时进入安全状态而非危险状态
- **危险告警 (Hazard Warning)**：在危害发生前发出警告
- **安全集成 (Safe Integration)**：与其他系统集成时不引入新的危害

> Safety 对自动驾驶、医疗设备、工业控制系统等安全关键系统至关重要。

## 第二部分：CVSS 4.0 评分体系

> 来源：FIRST.org，CVSS 4.0 于 2023年11月正式发布

### 概述

CVSS 4.0 是当前最新版本，相比 CVSS 3.1 提供更细粒度的评估维度，简化评分流程，增强可扩展性。

### 评分维度

CVSS 4.0 评估以下维度：

**基础指标 (Base Metrics) - 必填**：
- 攻击向量 (AV)：网络(N)/邻接(A)/本地(L)/物理(P)
- 攻击复杂度 (AC)：低(L)/高(H)
- 攻击要求 (AT)：无(N)/存在(P)
- 所需权限 (PR)：无(N)/低(L)/高(H)
- 用户交互 (UI)：无(N)/需要(P)
- 机密性影响 (VC)：高(H)/低(L)/无(N)
- 完整性影响 (VI)：高(H)/低(L)/无(N)
- 可用性影响 (VA)：高(H)/低(L)/无(N)

**补充指标 (Supplemental Metrics) - 可选**：
- 安全 (S)：存在(P)/不存在(N)
- 自动化 (AU)：无(N)/有(Y)
- 恢复 (R)：自动(A)/用户(U)/不可恢复(I)
- 价值密度 (V)：分散(D)/集中(C)
- 漏洞响应 (RE)：官方(O)/非官方(U)
- 供应商紧迫性 (U)：清晰(G)/合理(A)/未知(U)/红色(R)

**环境指标 (Environmental Metrics) - 可选**：
可针对特定环境调整基础指标值

### 定级对应

| 等级 | CVSS 4.0 分值 | 审计建议 |
|------|---------------|----------|
| 严重 (Critical) | 9.0 - 10.0 | 24~72 小时内修复或下线缓解 |
| 高 (High) | 7.0 - 8.9 | 1~2 周内修复 |
| 中 (Medium) | 4.0 - 6.9 | 1~3 个月内修复 |
| 低 (Low) | 0.1 - 3.9 | 按计划排期修复 |
| 信息 (Info) | 0.0 | 记录备案，无需立即修复 |

### 向量串格式

CVSS 4.0 向量串格式示例：
```
CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H
```

### 使用建议

- 审计报告中每条发现给出 CVSS 4.0 基础向量串与分值
- 结合业务上下文（数据敏感度、暴露面、利用条件）做最终定级
- 业务加权可在报告中说明，基础分值仍需客观给出

## 第三部分：国内合规参考

### 网络安全等级保护 2.0

- **GB/T 22239-2019**：信息安全技术 网络安全等级保护基本要求
- **GB/T 28448-2019**：信息安全技术 网络安全等级保护测评要求
- 定级：第一级（自主保护）~ 第五级（专控保护），第三级及以上为关键信息基础设施常见级别

### 法律法规

- 《中华人民共和国网络安全法》（2017年6月1日施行）
- 《中华人民共和国数据安全法》（2021年9月1日施行）
- 《中华人民共和国个人信息保护法》（2021年11月1日施行）

### 国家标准

- **GB/T 35273-2020**：信息安全技术 个人信息安全规范
- **GB/T 20984-2022**：信息安全技术 信息安全风险评估方法

### 信创环境兼容性

涉及国产化环境时关注：
- 操作系统：麒麟（Kylin）、统信 UOS
- 数据库：达梦（DM）、人大金仓（Kingbase）、OceanBase
- 中间件：东方通（TongWeb/TongTech）、宝兰德（BES）
- CPU：飞腾、鲲鹏、龙芯、海光
- 已知安全公告与漏洞需跟踪各厂商安全通告

## 第四部分：其他参考标准

### NIST SSDF (SP 800-218 v1.1)

安全软件开发框架，四个实践组：
- PO (Prepare the Organization)：组织准备
- PS (Protect Software)：保护软件
- PS (Produce Well-Secured Software)：生产安全软件
- RV (Respond to Vulnerabilities)：响应漏洞

### NIST SP 800-53 Rev. 5

安全和隐私控制目录，覆盖 20 个控制族（AC 访问控制、AU 审计与问责、SC 系统与通信保护等）。

### PCI DSS 4.0.1

支付卡行业数据安全标准，6.2.4 要求要求对照 OWASP Top 10 进行安全验证。

### Google Core Web Vitals

- **LCP (Largest Contentful Paint)**：≤ 2.5s
- **INP (Interaction to Next Paint)**：≤ 200ms（2024年3月起取代 FID）
- **CLS (Cumulative Layout Shift)**：≤ 0.1

### 性能参考基线（最终以项目 SLO 为准）

- API 响应 P95 < 500ms
- 慢查询阈值 > 100ms
- GC 停顿 P99 < 200ms

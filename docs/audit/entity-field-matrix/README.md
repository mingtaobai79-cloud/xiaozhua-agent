### 一条贯穿全目录的错因（读之前记住）

**①②④ 是同一个病：看到空结果，就给它编一个机制。**
- 「审计没记录」→ 推断"类型 UPDATE 不写审计"
- 「batch=0」→ 推断"时序边沿"
- 「表里没有」→ 推断"不存在"（⑤）

⇒ **判据：空结果只能记为"未观测到"，不能升级为"机制上不会"。**
   要给它机制，必须另有独立证据（这也是本目录后来统一把结论降为 `UNVERIFIED` 的原因）。

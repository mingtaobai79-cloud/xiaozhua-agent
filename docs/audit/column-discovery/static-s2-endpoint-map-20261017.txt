=== 8. 推断（明确标注，不与上述事实混排）===
  推断 1（推断，非 LIVE）：S2 页面建「栏目分组」时，前端打的应是 udcPortletCreatePost，
    即 REST /service/udc/portlet/create（PortletDto，type=GROUP），而不是 /udc/portlet-group/create（PortletGroupDto）。
    依据：(a) 前端 chunk 里 portlet-group 字样 0 次、udcPortletGroup* op 0 个；
          (b) udcPortletCreatePost 的返回体含 portletList + groupId + type，与 udc_portlet 树一致；
          (c) PortletGroupDto 无 type/groupId/parent 语义，指向 udc_portlet_group（0 行空表）。
    证伪方式（恢复后必做）：抓页面真实请求，看命中哪条路径。若命中 portlet-group，则本推断错误，须现场改判。
  推断 2（推断）：S1「分组父级 = udc_portlet 自己的 type=0 行」由此得到静态支持——
    因为分组写入走 udc_portlet（group_id 自引用），而 udc_portlet_group 是全库 0 行的另一张树表（parent_id/tree_path）。
    但 udc_portlet_group 究竟服务于哪个 UI 面，本片不取证，保持 UNVERIFIED。
